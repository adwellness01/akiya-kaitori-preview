TWO SIDES

借地権と底地、
どちらもお任せください

1つの土地に2つの権利が重なっているのが、この分野の難しさです。

他人の土地を借りて自分の建物を建てている場合、建物の所有者が持つ権利が借地権、土地の所有者（地主）が持つ権利が底地です。どちらも単独では買い手が付きにくく、価格も割安になりがちです。当社は両方の立場から買取を行っているため、どちらのご相談でも対応できます。

対応できる権利の種類

TYPE 01旧法借地権
平成4年8月より前に設定された借地。存続期間の考え方が現行法と異なります
TYPE 02普通借地権・定期借地権
借地借家法に基づく借地。更新の有無で扱いが変わります
TYPE 03底地（貸宅地）
借地人が建物を所有している土地。地代が低いままのケースが多い
TYPE 04使用貸借・権利関係が不明
親族間で地代を取っていない、契約書が残っていないケースも

地主が譲渡を承諾しない

借地権を売りたいのに地主の承諾が得られない。承諾料の折り合いがつかない。

更新の時期が近い

更新料を請求されたが金額に納得できない。更新を機に手放したい。

相続したが地主と面識がない

親から借地を相続したものの、地主が誰なのか、契約内容もよく分からない。

地代が安すぎる（地主側）

昔の水準の地代のまま。値上げ交渉も難しく、収益にならない底地を持て余している。

借地上の建物が老朽化

建て替えには地主の承諾が必要。住む予定もなく、朽ちるのを待つしかない状態。

借地と底地をまとめたい

借地人・地主の双方が売却を検討している場合、同時売買でまとめる進め方もあります。

契約書が見つからない、地主の連絡先が分からない——その状態からでもご相談いただけます。
